Features

What it does

No MIDI knowledge required. Paste a Spotify link and get a playable chart.

🎧

Spotify → Chart

Paste a Spotify track or playlist URL. Metadata is pulled from the public page — no API keys, no accounts, no setup.

📋

Playlist Mode

Paste a playlist URL and it'll process every track in sequence. Queue up 50 songs and come back to 50 charts.

🤖

Gemini AI Engine

Uses Gemini 2.0 Flash to identify song sections and build note patterns per difficulty. Also turns plain lyrics into synced karaoke tracks.

🎤

Synced Lyrics

Fetches time-synced LRC lyrics from LRCLIB. Gemini fills in gaps and aligns everything to the song's actual sections.

🎚️

4 Difficulty Levels

Easy through Expert, each with its own note grid. Orange fret and chords introduced progressively as difficulty increases.

📺

Music Video Background

Downloads the official music video from YouTube and bundles it as a background. Works automatically, disable it if you don't want it.

🥁

Beat Detection

librosa extracts onsets, tempo, and pitch from the audio. Notes land on detected beats — nothing's placed at random.

📦

Ready to Play

Outputs a Clone Hero song folder with notes.chart, song.ini, lyrics, album art, and audio. Drop it in your Songs folder and play.

Pipeline

How it works

From a Spotify URL to a playable chart folder.

01

Resolve

Reads song title, artist, album, year, and duration from the public Spotify page. For playlists, it grabs every track at once. No auth needed.

02

Download

Grabs the audio and optional music video from YouTube. Fetches synced lyrics from LRCLIB at the same time.

03

Analyze

librosa detects beats, onsets, and pitch. Gemini maps out song sections, syncs lyrics, and designs note patterns for each difficulty.

04

Generate

Writes a .chart file with all 4 difficulties plus lyric tracks, builds the metadata, and packages it into a Clone Hero folder.

CLI

Commands and flags

Run songhero - for interactive mode if you prefer prompts over flags.

Command / Flag What it does
songhero <url> Chart a single Spotify track
songhero <playlist-url> Batch-chart an entire Spotify playlist
songhero - Interactive mode — set options, manage keys, queue tracks
--lyrics / --no-lyrics Enable or disable synced lyric fetching from LRCLIB
--gemini / --no-gemini Enable or disable Gemini AI enhancement of charts and lyrics
--video / --no-video Enable or disable music video background download
--rewrite Overwrite an existing chart folder instead of skipping it
--output <dir> Set a custom output directory for chart folders
--keep-temp Keep intermediate files (audio, lyrics, analysis) for debugging
Install

Get it running

macOS and Linux. Windows works through WSL.

$ curl -sSL https://raw.githubusercontent.com/jackwallner/portfolio/main/docs/songhero/install.sh | bash
$ git clone https://github.com/jackwallner/any-song-clone-hero-cli.git
$ cd any-song-clone-hero-cli && chmod +x index.js
Prerequisites: brew install yt-dlp ffmpeg · pip3 install librosa soundfile numpy scipy google-generativeai
